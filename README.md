# Umbrella Corporation Manager

Консольная программа для управления учёными и проектами.

## Функции

### Учёные
- Добавить учёного
- Удалить учёного
- Показать список
- Список должностей

### Проекты
- Добавить проект
- Удалить проект
- Показать список
- Лаборатории

### Данные
- Сохранение в файлы (`Scientist.txt`, `Projects.txt`)
- Загрузка при старте

## Как запустить

1. Установить [.NET 8](https://dotnet.microsoft.com/download)
2. Клонировать репозиторий:
   `git clone https://github.com/kazxcmaz/Umbrella-Corporation.git`
3. Перейти в папку:
   `cd Umbrella-Corporation`
4. Запустить:
   `dotnet run`

## Технологии
- C#
- .NET 8
- `System.IO` (работа с файлами)
- `List<T>` (коллекции)
